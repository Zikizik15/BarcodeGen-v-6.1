# barcodeGen

Генератор штрихкодов и QR-кодов с поддержкой пакетной обработки и визуальным редактором шаблонов этикеток.

## Возможности

- 📦 **Пакетная генерация** — обрабатывайте списки кодов из файла или вручную
- 🎨 **Редактор шаблонов** — создавайте собственные раскладки этикеток
- 🖼️ **Логотипы и текст** — добавляйте на этикетку логотип и произвольные надписи
- 📄 **Экспорт в PDF** — готовая печать или отправка на принтер
- 🗜️ **Экспорт в ZIP** — отдельные изображения для каждого кода
- 📊 **Экспорт в Excel** — список сгенерированных кодов
